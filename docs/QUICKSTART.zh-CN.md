# DeskMesh（桌联）中文使用说明

本文适用于 `v0.1.0-alpha.6`。DeskMesh 只应运行在你信任的家庭专用局域网中。

## 1. 安装、启动与卸载

1. 从 [GitHub Releases](https://github.com/bz1121/deskmesh/releases) 下载 Windows x64 ZIP 与 `SHA256SUMS.txt`。
2. 使用 `Get-FileHash <zip> -Algorithm SHA256` 校验后，在两台电脑分别解压。
3. 运行解压目录根部唯一的自包含程序 `DeskMesh.exe`。不要单独移动该文件，旁边的 `wwwroot`、`docs`、`licenses` 与配置文件需要一起保留。程序仅为当前登录用户运行，不安装 SYSTEM 服务。
4. Windows 防火墙弹窗只勾选“专用网络”。
5. 首次使用时从 DeskMesh 托盘菜单打开控制台，不要直接从浏览器开始管理员设置。

当前 Alpha 尚未进行 Authenticode 签名。若官方 ZIP 的 SHA-256 已与 Release 页面一致，但 SmartScreen 仍显示“发布者未知”，可选择“更多信息 → 仍要运行”。也可以在**解压前**对已验证的 ZIP 执行 `Unblock-File .\DeskMesh-<版本>-win-x64.zip`，再重新解压；不要全局关闭 SmartScreen，也不要对来源不明的副本解除锁定。

端口：

- 本机控制台：`127.0.0.1:5616/TCP`
- 设备间 HTTPS/WSS：`45832/TCP`
- 自动发现：`45830/UDP`

卸载前从网页关闭“登录后自启动”，退出托盘程序，再删除解压目录。若不再需要配置，可手动删除 `%LOCALAPPDATA%\DeskMesh`；早期测试版本可能继续使用 `%LOCALAPPDATA%\LanSwitch`。删除数据目录会永久失去配对身份与显示器映射。

## 2. 本机管理员设置与登录

每台电脑分别维护一个 DeskMesh 本机管理员。它只用于解锁该电脑的网页控制台，不上传到云端，也不会同步给另一台电脑。

1. 在当前电脑的 DeskMesh 托盘菜单中选择打开控制台。首次设置时，Agent 会生成有效期 10 分钟、仅能使用一次的引导并打开 `http://127.0.0.1:5616/`；直接输入网址只能看到“请从托盘完成首次设置”。再次从托盘打开会废止先前尚未使用的引导。
2. 创建管理员名称和至少 6 个字符的密码（建议使用更长且不复用的密码）。引导使用一次后立即失效；两台电脑需要分别设置。
3. 设置完成后进入控制台。会话连续空闲 15 分钟或总时长达到 2 小时后失效；Agent 重启、主动锁定或退出登录也会要求重新输入该电脑的管理员名称和密码。
4. 10 分钟内连续 5 次登录失败会锁定 5 分钟。请等待页面显示的锁定时间结束，不要反复尝试。
5. 忘记密码或看到“管理员凭据需要恢复”时，在该电脑的 DeskMesh 托盘菜单中选择“重置控制台登录…”。系统确认框默认选择“否”；明确选择“是”后，DeskMesh 会结束全部本机网页会话、只清除管理员凭据，并自动打开新的首次设置页。设备身份、已配对设备和显示器映射会保留。

从没有管理员登录功能的旧版本升级时，现有设备身份、配对关系、显示器映射和其他设置保持不变；升级后的控制台会处于“尚未设置管理员”状态。请从托盘打开控制台并完成一次首次设置，不需要重新配对或重新校准。

这里的“管理员”是 **DeskMesh 应用管理员**，不是 Windows 管理员。登录不会提升进程权限或绕过 UAC。可选安全桌面组件必须另行通过 Windows UAC 安装；默认只处理 UAC，锁屏扩展还需在目标端明确开启并配置 Windows 软件安全注意序列策略。DeskMesh 不能防御已在同一 Windows 用户下运行的恶意代码或已控制该用户浏览器的攻击者。

本机网页管理员和局域网设备身份是两套边界：网页只监听 `127.0.0.1` 并要求本机登录；Agent 之间继续使用配对关系、mTLS 和证书指纹。管理员登录不能代替设备配对，配对成功也不能远程打开对方的管理员页面。不要从另一台电脑访问本机控制台。

## 3. 接线

- 共用显示器时，台式机接 `HDMI1`，笔记本接 `DP`。
- 键盘和鼠标接到日常操作的电脑，下文称“键鼠主机”。
- 耳机接在键鼠主机，并设为 Windows 默认播放设备。
- 显示器 OSD 有 `DDC/CI` 时请开启；没有该菜单也可先做普通探测。

不共用显示器时仍可使用远程桌面、音频、剪贴板、文件和键鼠功能，无需 DDC/CI。

## 4. 配对

1. 在目标电脑打开“安全与配对”，点击“生成并复制新码”。
2. 在另一台电脑填写目标 IPv4 与端口，例如 `192.168.1.24:45832`，再填写六位码。
3. 两端核对中文安全短语和证书指纹。
4. 在目标电脑批准请求。

每次生成新码都会立即废止旧码；配对码五分钟后过期。自动发现使用 TTL=1 组播和每张活动私有 IPv4 网卡的同子网定向广播，不扫描其他主机。发现失败时使用手动 IP，并检查两端 `DeskMesh.exe` 的专用网络防火墙规则。

## 5. 先开启需要的能力

为保护隐私，新安装默认关闭以下功能：

- 自动剪贴板同步
- 音频随控制目标
- 允许已配对设备查看和控制本机桌面

请在两台电脑的本机控制台按需开启。批准配对代表你信任该设备；当前 Alpha 尚未提供逐设备的细粒度能力权限。

### 剪贴板

可分别开启文本、图片并选择双向、只发送或只接收。文本默认上限 1 MB，图片默认上限 20 MB。密码、令牌或隐私图片复制前可随时暂停同步。

### 文件拖放

在“文件传输”选择在线目标，把单个文件拖入上传区或点击选择。浏览器到本机 Agent 的暂存阶段可取消；接收端批准并选择路径后才开始局域网传输。文件最大 2 GB，先写 `.part`，完成 SHA-256 校验后再改为正式文件名。

### 远程桌面和音频

1. 在被查看电脑开启“允许已配对设备查看和控制本机”。
2. 在控制端选择在线设备和目标屏幕，开启远程桌面。
3. 需要声音时，两端开启“音频随控制目标”，并确认控制端耳机是默认输出。

画面使用 GDI/JPEG 兼容路径，支持 2–90 FPS 配置；建议先用 20–30 FPS。90 FPS 仅为目标上限，实际取决于 CPU、分辨率和有线/无线网络。音频转发远端系统回放，不采集麦克风，也不会自动静音远端扬声器。

### 两种切换方式

- **直接信号**：调用显示器 DDC/CI 切换 HDMI/DP，再交接系统级键鼠；画质、刷新率与 HDR 由显示器直接输出，但切源时可能短暂黑屏。需要先完成第 7 节校准。
- **无缝远程**：保持当前显示器输入不变，通过远程桌面在控制台中显示并控制对方；第一帧成功绘制后才进入全视口，超时、断流或按 Esc 会清除画面并返回本机。此模式不调用 DDC/CI，不要求显示器映射，但对方必须开启远程桌面权限。

无缝远程使用远程桌面会话自带的画面内输入，不会同时开启系统级全局键鼠转发。控制台标签必须保持打开、位于前台并获得焦点；全局切换快捷键会向该标签发起请求，如果控制台未打开或在后台则不会降级为直接切源。托盘“切换到另一台电脑”在此模式下只打开控制中心，请在页面中选择目标设备。

### 可选 AI 诊断

在“管理员设置 → AI 诊断与安全修复”填写 OpenAI 兼容 API 基础地址、模型名称和 API Key。官方 OpenAI 地址为 `https://api.openai.com/v1`；其他电脑上的服务必须使用 HTTPS，只有本机回环地址允许 HTTP。保存后可手动执行一次安全分析。

AI 默认关闭，也不会接收屏幕、音频、剪贴板、文件内容、密码、配对码、API Key、设备标识、IP、证书指纹或 Windows 路径。API Key 由 Windows DPAPI 单独保护，不写入普通设置。模型只能建议固定的三种动作：回到本机、重新探测显示器、关闭实体跟随；DeskMesh 不接受或运行模型生成的命令、脚本、注册表修改和文件操作。“自动执行低风险修复”必须另行显式开启，最多每 10 分钟分析一次，并由本机状态再次确认。

## 6. 快捷键与键鼠切换

- 切换本机/远端：默认 `Ctrl+Alt+Shift+F12`
- 直接回本机：默认 `Ctrl+Alt+Shift+F11`
- 紧急释放回本机：固定 `Ctrl+Alt+Shift+Esc`

前两个可在网页中修改；紧急键不可修改。直接信号模式下，键鼠主机负责捕获并转发普通登录桌面的输入。无缝远程模式下，控制台标签必须保持打开、位于前台并获得焦点以响应远端切换快捷键；切回本机和紧急键仍会立即关闭无缝会话。网络断开、输入通道异常或队列无法安全保留按键状态时，DeskMesh 会释放按键并回本机。

## 7. HDMI1 与 DP 普通校准

不要直接套用网上常见 VCP 值；不同显示器可能使用不同代码。

1. 用显示器实体键切到台式机 `HDMI1`，在台式机点击“探测 DDC/CI 能力”，记录稳定当前值。
2. 用实体键切到笔记本 `DP`，在笔记本重复探测并记录当前值。
3. 在两台电脑各自的控制台，都为**本机显示器身份**保存两条映射：
   - 台式机 → HDMI1 → 实测值
   - 笔记本 → DP → 实测值
4. 确认两条映射属于同一 MonitorId 且数值不同。
5. 保持显示器实体摇杆可用，执行一次去程与回程测试。

例如实测 HDMI1=`5`、DP=`7`，两台电脑都应各自保存这两个“设备 → 输入值”关系。MonitorId 是本机拓扑身份，不能从另一台复制。

“实体按钮切源后键鼠跟随”只在键鼠主机开启，另一台保持关闭。新输入端 Agent 必须连续两次稳定确认当前画面，键鼠才会跟随。

## 8. 只写 DDC 兼容模式

仅在普通探测无法读取 VCP `0x60`、但显示器可能接受写命令时使用：

1. 先完成一次显示器身份探测。
2. 勾选黑屏恢复确认并开启只写模式。
3. 分别测试 HDMI1 `0x11` 和 DP `0x0F`；DeskMesh 不扫描其他值。
4. 每次测试后观察物理画面，如实选择“确定”或“取消”。
5. 两项均目视确认，并为本机与远端保存不同映射后，自动联动才会开放。

“命令已发送”不等于“切换成功”。该模式无法读取当前输入，因此不能使用实体按钮跟随；紧急快捷键只保证键鼠回本机，无法保证画面已经回切。请始终保留显示器实体摇杆。

## 9. 常见问题

### 首次设置页面要求从托盘打开

这是预期行为。未配置的控制台不会接受普通网页直接注册管理员。请关闭当前页面，从运行中的 DeskMesh 托盘菜单重新打开控制台；一次性引导失效后也需要重新从托盘打开。

### 忘记管理员密码或登录被锁定

临时锁定时先等待页面倒计时结束。忘记密码或凭据损坏时，从本机 DeskMesh 托盘选择“重置控制台登录…”，在系统确认框明确选择“是”；重置成功后会自动打开新的首次设置页，且不会删除设备身份、配对关系或显示器映射。不要通过删除整个数据目录来重置密码，否则会同时永久删除这些设备数据。

### 页面显示 Agent 离线

确认托盘程序仍在运行，刷新 `127.0.0.1:5616`。不要从另一台电脑直接访问该本机控制台。

如果升级后页面仍显示旧名称“LanSwitch”、已移除的“局域网更新”，并同时出现 `Administrator setup is required.` 与 Agent 离线提示，说明浏览器仍在使用旧版控制台资源。先按 `Ctrl+F5` 强制刷新，再从 DeskMesh 托盘重新选择“打开控制台”，以获取新的 10 分钟一次性首次设置链接。后续版本会主动禁止复用旧控制台缓存。

### 自动发现不到设备

确认两台机器同属家庭“专用网络”，关闭 AP 客户端隔离，检查 `45830/UDP` 和 `45832/TCP`。再尝试手动 IP。

### 切换后鼠标回弹或自动回本机

查看“诊断日志”。输入 WebSocket 关闭、目标离线、键鼠钩子异常或 DDC/到达确认失败都会触发安全回退。先降低远程桌面 FPS，确认两端版本一致并使用有线网络，再重新测试。

### 远端没有声音

确认两端已开启音频、远端 Windows 正在播放、控制端耳机是默认输出。插拔耳机后重新建立远程会话。音频失败不会主动断开画面。

### 控制 UAC 或已登录后锁定的会话

普通 `SendInput` 无法跨越 UAC 安全桌面。若确实需要在远端电脑确认 UAC：

1. 在**被控制的目标电脑**打开“管理员设置”。
2. 找到“UAC 安全桌面控制”，点击“安装安全桌面组件”。
3. 在 Windows UAC 窗口明确选择允许；另一台目标电脑也要单独安装。
4. 重新建立控制会话。出现 UAC 时，DeskMesh 只转发键鼠，仍由你决定是否点击“是”。

若还需要解锁**已经登录后再锁定**的当前会话：

1. 只在可信私人电脑上，打开目标端同一卡片的“允许控制已锁定的当前 Windows 会话”。
2. 若需要 Ctrl+Alt+Del，在目标端运行 `gpedit.msc`，进入“计算机配置 → 管理模板 → Windows 组件 → Windows 登录选项 → 禁用或启用软件安全注意序列”，设为“已启用”并选择“服务”。DeskMesh 不会替你修改该策略；没有该策略项的 Windows 版本不承诺此功能。
3. 在已连接的远程桌面工具栏点击“Ctrl+Alt+Del”。进入锁屏后，键鼠通道会继续，但远程 GDI 画面无法采集 Winlogon；必须查看目标电脑实体/共享显示器后自行输入密码。

组件以 LocalSystem Windows 服务运行，但只接受当前用户 DeskMesh Agent 的固定键盘/鼠标消息；不接受命令行、脚本、文件路径或模型生成的自由文本。卸载同样从该卡片发起并需要 UAC 确认。DeskMesh 不读取、保存或代填 Windows 密码。开机登录、注销后的登录、BIOS 和部分反作弊程序仍不支持，请使用硬件 KVM 或 Windows 远程桌面。

### DDC 探测失败

确认显示器 OSD、线材与显卡驱动。普通模式失败时再谨慎测试只写模式；任一固定值测试失败，就使用实体键或硬件 KVM。

## 10. 实机验收清单

正式使用前至少验证：

- 中文/英文输入法、左右修饰键、长按键、滚轮和侧键
- 断网、目标休眠、Agent 被结束及快速连续切换
- 剪贴板暂停、文本/图片超限
- 文件拒绝、取消、同名、中途断网和最终 SHA-256
- 远程桌面多屏、10/30/60 FPS、耳机插拔和默认输出变化
- HDMI1↔DP 往返、显示器休眠唤醒及实体键恢复
- 管理员首次设置链接的一次性使用、登录失败锁定、会话到期、托盘重置及重置后配对/映射仍存在

遇到安全问题请阅读 [SECURITY.md](../SECURITY.md)；普通故障反馈见 [SUPPORT.md](../SUPPORT.md)。提交日志前请删除配对码、证书指纹、IP、用户名和私人文件名。
